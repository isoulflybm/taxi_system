# Архитектура Taxi KG — начальное решение

## Основа

- Backend: Django 5.2 LTS, GeoDjango, Django REST Framework.
- База: PostgreSQL + PostGIS.
- Realtime: Django Channels + Redis.
- Карта браузера: MapLibre GL JS.
- Геоданные базовой карты и бизнес-объекты хранятся раздельно; интеграция тайлов/маршрутизации будет отдельным модулем.

## Доменные приложения

- `accounts`: клиенты, водители, операторы и роли.
- `fleet`: транспорт и документы автомобилей.
- `orders`: заказ, адреса, цена и статусы заявки.
- `trips`: назначение и фактическое выполнение поездки.
- `dispatch`: очередь заказов и ручное/автоматическое назначение.
- `tariffs`: тарифные зоны и правила расчёта.
- `tracking`: поток координат и последняя известная позиция.
- `geo`: точки, районы обслуживания, импорт и адаптеры картографии.

Пока приложения — только каркас. Модели и API будут добавляться после фиксации правил тарификации, статусов и назначения водителя.

## Карта и геолокация

- Диспетчерская карта: `/dispatch/map/`; MapLibre читает стиль из `MAP_STYLE_URL`. По умолчанию это OpenFreeMap Liberty на данных OpenStreetMap; источник можно заменить своим стилем.
- Стартовая выборка: `GET /api/dispatch/map/` — активные заказы и последняя координата каждого водителя.
- Водительская страница: `/driver/location/`; браузер через `navigator.geolocation` отправляет координаты раз в несколько секунд при открытой странице.
- Приём координат: `POST /api/tracking/location/`; сессия браузера или DRF token, разрешён только профилю с ролью `driver`. Поля включают WGS84, время фиксации и точность GPS.
- WebSocket `/ws/dispatch/locations/` рассылает новые позиции только диспетчерам и администраторам.
- Для Redis-подключения Channels явно задан `socket_timeout=None`: его приём сообщений блокирующий, а тайм-аут redis-py 8 по умолчанию приводил к отключению простаивающих WebSocket.
- Поиск адреса: `GET /api/geo/search/?q=...`; вручную инициируемый запрос через `NOMINATIM_BASE_URL`, результат ограничен Кыргызстаном и кэшируется.
- Стандартные растровые тайлы OSM сейчас отвечают `403`; для прототипа используется OpenFreeMap, для рабочей нагрузки нужен собственный tile-сервер или провайдер с SLA.
- Публичный Nominatim не используется по умолчанию: Taxi KG относится к сервисам отслеживания автомобилей, для которых политика Nominatim требует собственный сервис геокодирования.
- Аппаратные трекеры обычно подключаются через шлюз вроде Traccar, который понимает их TCP/UDP-протоколы; Django принимает нормализованные координаты по API.

## Следующие задачи

1. Развернуть собственные тайлы Кыргызстана и настроить их стиль/источник.
2. Поднять собственный Nominatim или выбрать коммерческий геокодер и указать `NOMINATIM_BASE_URL`.
3. Подключить Traccar и адаптер его событий к API Taxi KG для реальных устройств.
4. Подключить маршрутизатор, чтобы считать дорожное расстояние и время поездки.
5. Добавить назначение водителей, ограниченный срок хранения координат и очистку истории.

Роль Taxi KG и телефон задаются непосредственно в Django Admin на форме пользователя. `UserProfile` создаётся автоматически и не добавляется вручную.
